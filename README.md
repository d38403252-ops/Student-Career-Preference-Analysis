# Student Career Preference Analysis

## Government vs. Private Employment Preferences

### Project Overview

This project explores students' preferences for government and private-sector employment using a reproducible synthetic dataset of 1,000 student records.

It demonstrates an end-to-end data analytics workflow, including dataset generation, data cleaning, exploratory data analysis, visualisation, SQL querying, and interactive dashboard development using Power BI.

The dataset is synthetic and is intended for educational and portfolio purposes. It does not represent responses from a real student survey.

### Objectives

- Compare preferences for government and private-sector employment.
- Explore expected salary patterns and career decision factors.
- Examine government exam preparation trends.
- Compare career preferences across degree categories.
- Practise data preparation, analysis, visualisation, and SQL workflows.
- Build an interactive dashboard using Power BI.

### Tools and Technologies

- **Python:** Pandas, NumPy
- **Data Visualisation:** Matplotlib, Seaborn
- **Database:** SQLite
- **Querying:** SQL
- **Business Intelligence:** Microsoft Power BI
- **Version Control:** Git and GitHub

### Dataset

The project generates 1,000 synthetic student records containing education details, career preferences, salary expectations, preferred skills, and employment-related choices.

The generated files are organised under `data/`:

- `data/raw/` — generated source CSV files.
- `data/processed/` — cleaned dataset used for analysis.
- `data/database/` — database-related files and exported analysis results.

### Project Workflow

1. Generate a synthetic student dataset using Python.
2. Clean and prepare the dataset.
3. Perform exploratory data analysis.
4. Generate charts using Matplotlib and Seaborn.
5. Create an insights report.
6. Load the cleaned dataset into an SQLite database.
7. Perform data analysis using SQL queries.
8. Import the dataset into Power BI.
9. Create interactive visualisations and dashboard KPIs.
10. Present the findings through charts, reports, and a dashboard.

## Power BI Dashboard

This interactive Power BI dashboard presents insights from a synthetic dataset of 1,000 students, analysing their career preferences, demographics, and educational backgrounds.

### Key Visualizations

- Total Student Count
- Preferred Employment Sector
- Gender Distribution
- Degree Distribution
- Age-wise Student Distribution
- Department-wise Student Distribution

### Key Insights

- Provides an overview of the total number of students analysed.
- Visualises students' preferred employment sectors.
- Compares gender distribution across the dataset.
- Highlights the distribution of students by degree and department.
- Explores the age distribution of students.
- Enables interactive exploration of student career preferences.

### Dashboard Files

The Power BI dashboard and its screenshot are available in the `powerbi/` directory.
