# Student Career Preference Analysis

## Government vs. Private Employment Preferences

### Project Overview

This project explores students' preferences for government and private-sector employment using a reproducible synthetic dataset of 1,000 student records. It demonstrates a basic data analytics workflow, from dataset generation and cleaning to exploratory analysis, visualisation, and insight reporting.

The dataset is synthetic and is intended for educational and portfolio purposes. It does not represent responses from a real student survey.

### Objectives

- Compare preferences for government and private-sector employment.
- Explore expected salary patterns and career decision factors.
- Examine government exam preparation trends.
- Compare career preferences across degree categories.
- Practise data preparation, analysis, visualisation, and SQL workflows.

### Tools and Technologies

- **Python:** Pandas, NumPy
- **Visualisation:** Matplotlib, Seaborn
- **Database:** SQLite
- **Querying:** SQL
- **Version control:** Git and GitHub

### Dataset

The project generates 1,000 synthetic student records containing education details, career preferences, salary expectations, preferred skills, and employment-related choices. The generated files are organised under `data/`:

- `data/raw/` — generated source CSV files.
- `data/processed/` — cleaned dataset used for analysis.
- `data/database/` — SQLite database created from the cleaned data.

### Project Structure


### Workflow

1. Generate the synthetic student dataset.
2. Clean and prepare the data.
3. Explore career preferences and related attributes.
4. Generate visualisations from the analysis.
5. Produce a text-based insights report.
6. Load the cleaned data into an SQLite database.
7. Review the SQL queries provided in `sql/`.
